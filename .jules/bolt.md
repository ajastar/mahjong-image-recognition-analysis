## 2024-05-18 - [Optimization] Generator Comprehensions in sum() hurt performance
**Learning:** In hot-path functions (like those in `mahjong_logic.py` that are called frequently during shanten calculation and simulation), Python generator comprehensions inside `sum()` (e.g., `sum(1 for x in arr if condition)`) incur significant overhead. However, expanding these to multi-line `for` loops severely degrades code readability for what is essentially a micro-optimization. The reviewer noted that replacing elegant one-liners with verbose loops sacrifices readability.
**Action:** When optimizing aggregations like `sum()`, if readability would be compromised by explicit `for` loops, prefer more efficient one-liners such as using `len([x for x in arr if condition])` over `sum(1 for x in arr if condition)` which gives a ~30% performance boost without expanding lines of code, or only use loops if the logic warrants it.
