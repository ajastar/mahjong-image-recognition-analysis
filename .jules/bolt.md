## 2024-06-18 - Avoid Dynamically Generating Static Lists
**Learning:** Flatten dynamically generated static lists and replace generator comprehensions inside `sum()` with unrolled index addition or module-level frozensets for membership testing to avoid allocation and iteration overhead in hot paths.
**Action:** Always extract static reference data, especially `terminals = [0,8,9,17,18,26] + list(range(27,34))`, into module-level frozensets like `TERMINALS_SET = frozenset([0,8,9,17,18,26,27,28,29,30,31,32,33])` in Python files to improve hot-path performance. Avoid generating lists via concatenation inline, as it triggers significant allocation overhead. When checking small arrays of fixed lengths, unrolled additions without comprehension (e.g., `a[0]+a[1]+a[2]...`) are notably faster than `sum(a[i] for i in [...])`.
