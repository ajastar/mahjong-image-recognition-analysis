## 2024-08-19 - Caching Hot Path Functions With Small Domains
**Learning:** Adding `@functools.lru_cache` to small-domain mathematical functions like `get_suji` (which computes safe tiles based on modulo arithmetic and is called repeatedly during simulation and encoding loops) provides significant (~40-46%) performance boosts in pure Python. However, functions returning mutable objects like lists will crash (with `AttributeError` from consumers trying to mutate the list, or from cache pollution) if `lru_cache` is applied directly.
**Action:** When memoizing functions with small domains (e.g., Mahjong tiles 0-33) that return lists, always refactor them to return an immutable `tuple` and strictly verify via codebase search that no downstream callers expect a mutable list to prevent runtime regressions.
