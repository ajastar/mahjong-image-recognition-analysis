## 2024-05-24 - [Optimize generator comprehensions inside sum()]
**Learning:** In CPython hot-path functions, evaluating generator comprehensions inside `sum()` (e.g., `sum(1 for x in obj)`) introduces significant function call overhead compared to explicit loops or boolean arithmetic.
**Action:** Optimize by replacing these with list comprehensions evaluated by `len()` (e.g., `len([x for x in obj if condition])`) or unroll boolean additions (e.g., `(a > 0) + (b > 0)`) for small fixed structures, to avoid overhead dynamically generated by generators.
