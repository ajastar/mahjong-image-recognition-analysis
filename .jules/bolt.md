## 2024-05-18 - [Optimize Terminal Index Lookups and Hot Loop Sums]
**Learning:** In CPython, redefining small, static sets of constant integers (`[0,8,9,...] + list(range(27,34))`) dynamically inside functions or loops incurs severe overhead due to list allocation, concatenation, and O(N) membership testing. Furthermore, generator expressions inside `sum()` incur function call overhead for frame allocation and `next()` calls compared to unrolled additions.
**Action:** Always predefine static lists as module-level `frozenset` objects to leverage fast O(1) membership lookup. When calculating the sum of multiple fixed array indices, use an unrolled sequence of additions (e.g. `hand_34[0] + hand_34[8] + ...`) rather than passing a generator expression or a list slice to `sum()`.
