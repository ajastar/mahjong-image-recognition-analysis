
## 2024-06-28 - Fast Static Array Membership and Iteration in Hot Paths
**Learning:** In CPython hot-path functions (like `mahjong_logic.py`), using dynamically generated static lists via addition/concatenation (e.g., `[0,8,9] + list(range(27,34))`) or local `list` variables for small, fixed iteration domains causes measurable allocation overhead. Using module-level `frozenset` objects for O(1) membership testing (`in TERMINALS_SET`) and `tuple` objects for iteration provides significant speedups (up to 12x faster than repeated list allocation). Furthermore, generator expressions evaluated inside `sum()` (e.g., `sum(1 for x in obj if cond)`) carry heavy function call overhead; replacing them with list comprehensions evaluated by `len()` (`len([x for x in obj if cond])`) is approximately 1.7x faster.
**Action:** When implementing algorithms that frequently test membership or iterate over small, constant domains, define module-level `tuple`s and `frozenset`s to avoid allocation overhead. In performance-critical loops, avoid generator expressions inside `sum()`; prefer `len()` with list comprehensions or unrolled explicit `for` loops. Always ensure exact variable names are replaced during refactoring to prevent `NameError` regressions.
