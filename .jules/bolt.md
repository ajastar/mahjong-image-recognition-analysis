## 2024-05-24 - Modulo 3 Optimization for Agari

**Learning:** `is_agari` loops through all 34 tiles checking if `hand_34[idx] >= 2` to use it as the head, and then tries to decompose the remaining 12 tiles into 4 melds. Since valid standard hands always have exactly 1 pair (sum=2 mod 3) and 4 melds (each sum=0 mod 3) per suit, the head MUST mathematically belong to the only suit with a tile count equal to 2 modulo 3. Other suits must be 0 modulo 3. Implementing this domain constraint acts as an early fast-fail filter for invalid hands and restricts the head search loop from 34 iterations down to 7 (honor) or 9 (suit) iterations, dramatically speeding up the core `is_agari` check used heavily in PIMC loops. Numpy sums inside the JIT function should be done with loops as numpy array slicing overhead is slow.
**Action:** When evaluating discrete tile sets with structural requirements, check arithmetic constraints (like sum modulo N) before performing combinatorial decomposition or iteration.
